# Página para Pau 💙

## Cómo abrirla
1. Descomprime el ZIP.
2. Abre `index.html` con Chrome/Edge/Opera.

## Música
No se incluyó una copia de la canción. Para usar tu archivo:
1. Consigue/usa el archivo de audio que quieras usar.
2. Renómbralo `cumple.mp3`.
3. Colócalo dentro de la carpeta `assets/`.
4. Abre de nuevo `index.html`.

La página ya tiene el botón de reproducción; los navegadores suelen bloquear el autoplay, por eso la canción empieza cuando se pulsa el botón.

## Subir a GitHub Pages
Sube todos los archivos manteniendo la estructura:
- `index.html`
- `style.css`
- `script.js`
- `assets/foto1.png` ... `foto6.png`
- `assets/cumple.mp3`

Después activa GitHub Pages desde la rama principal y la carpeta raíz.
